# Remote AI Chat CLI

Консольная программа для общения с LLM на удаленном Ollama сервере.

## Возможности

- ✅ Подключение к удаленному Ollama серверу
- ✅ Интерактивный чат (REPL)
- ✅ Настройка через переменные окружения или аргументы
- ✅ Команды: help, info, exit
- ✅ Обработка ошибок подключения

## Быстрый старт

### Вариант 1: Использование команды console-agent (рекомендуется)

Сначала установите команду (один раз):

```bash
./scripts/install-console-agent.sh
```

Затем используйте команду из любого места:

```bash
# Запустить Remote AI Chat
console-agent

# Или явно указать
console-agent remote
```

### Вариант 2: Через Gradle

```bash
./gradlew :console-agent:runRemoteChat
```

По умолчанию используется:
- Сервер: `http://193.42.127.171:11434` (уже настроенный удаленный сервер)
- Модель: `qwen2:7b-instruct`

### С настройкой через переменные окружения

```bash
# Указать свой сервер
export OLLAMA_BASE_URL=http://your-server:11434
export OLLAMA_MODEL=llama3
./gradlew :console-agent:runRemoteChat
```

### С аргументами командной строки

```bash
# Первый аргумент - URL сервера, второй - модель
./gradlew :console-agent:runRemoteChat -Premotechat.args="http://193.42.127.171:11434 qwen2:7b-instruct"
```

### Проверка перед запуском

Убедитесь, что удаленный сервер доступен:

```bash
# Проверить доступность
curl http://193.42.127.171:11434/api/version

# Проверить список моделей
curl http://193.42.127.171:11434/api/tags
```

## Доступные команды

- `help` - Показать справку по командам
- `info` - Показать информацию о сервере и модели
- `exit` или `quit` - Выйти из программы

## Конфигурация

### Переменные окружения

- `OLLAMA_BASE_URL` - URL удаленного Ollama сервера (по умолчанию: `http://193.42.127.171:11434`)
- `OLLAMA_MODEL` - Имя модели для использования (по умолчанию: `qwen2:7b-instruct`)

### Аргументы командной строки

1. `baseUrl` - URL сервера Ollama
2. `model` - Имя модели

## Требования

- Удаленный Ollama сервер должен быть доступен
- Модель должна быть загружена на удаленном сервере
- Сетевое подключение к серверу

## Устранение проблем

### Ошибка подключения

```
✗ Error: Could not connect to remote Ollama server
```

**Решения:**
1. Проверьте, что сервер запущен: `curl http://your-server:11434/api/version`
2. Проверьте доступность сети
3. Убедитесь, что порт не заблокирован файрволом

### Модель не найдена

```
Error: model 'model-name' not found
```

**Решение:** Загрузите модель на удаленном сервере:
```bash
ssh user@server
ollama pull model-name
```

### Медленные ответы

Ответы могут быть медленными в зависимости от:
- Размера модели
- Нагрузки на сервер
- Скорости сети
- Использования CPU/GPU на сервере

## Сравнение с Offline Chat

| Функция | Remote Chat | Offline Chat |
|---------|-------------|--------------|
| Сервер | Удаленный | Локальный |
| Требования | Сетевое подключение | Ollama локально |
| Настройка | URL через env/args | localhost:11434 |
| Использование | Для удаленных серверов | Для локальной разработки |
