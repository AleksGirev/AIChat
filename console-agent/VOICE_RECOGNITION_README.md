# Распознавание речи в консольном оффлайн агенте

Консольный оффлайн агент поддерживает голосовой ввод через команду `voice`.

## Быстрый старт

1. Убедитесь, что установлены инструменты для записи аудио:
   - **Linux**: `sudo apt-get install alsa-utils sox`
   - **macOS**: `brew install sox`

2. Запустите консольный агент:
   ```bash
   ./gradlew :console-agent:runOfflineChat
   ```

3. Используйте команду `voice` для записи голоса:
   ```
   You: voice
   🎤 Recording... (speak now, 5 seconds)
   ```

## Текущая реализация

Текущая реализация использует системные команды для записи аудио:
- **Linux**: `arecord` (ALSA) или `sox`
- **macOS**: `sox` или `rec`

После записи аудио, для полностью оффлайн распознавания речи требуется модель Vosk.

## Настройка Vosk для оффлайн распознавания

### Автоматическая установка (рекомендуется)

Используйте скрипт установки:

```bash
cd console-agent
./setup-vosk.sh
```

Скрипт автоматически:
1. Создаст директорию `vosk-models` в корне проекта
2. Скачает русскую модель `vosk-model-small-ru-0.22`
3. Распакует модель
4. Покажет инструкции по настройке

### Ручная установка

#### 1. Скачайте модель Vosk

Перейдите на https://alphacephei.com/vosk/models и скачайте модель для вашего языка:

- **Русский язык (малая модель)**: `vosk-model-small-ru-0.22` (~44 MB)
- **Русский язык (большая модель)**: `vosk-model-ru-0.42` (~1.8 GB)
- **Английский язык**: `vosk-model-small-en-us-0.15` (~40 MB)

#### 2. Распакуйте модель в проект

```bash
# Создайте директорию в проекте
mkdir -p vosk-models

# Распакуйте модель
cd vosk-models
unzip vosk-model-small-ru-0.22.zip
```

#### 3. Автоматическое определение

Агент автоматически найдет модель, если она находится в:
```
vosk-models/vosk-model-small-ru-0.22/
```

#### 4. Или установите переменную окружения

```bash
export VOSK_MODEL_PATH=/path/to/vosk-model-small-ru-0.22
```

Или добавьте в `~/.bashrc` или `~/.zshrc`:
```bash
export VOSK_MODEL_PATH=~/vosk-models/vosk-model-small-ru-0.22
```

## Использование

### Базовое использование

После установки модели Vosk:

```
You: voice
🎤 Recording... (speak now, 5 seconds)
✓ Recognized: посчитай 25 умножить на 17
AI: 25 умножить на 17 равно 425.
```

### Проверка установки

При запуске агента вы увидите:

```
✓ Vosk model found: /path/to/vosk-model-small-ru-0.22
```

Или, если модель не найдена:

```
⚠ Vosk model not found - voice recognition will be limited
  Download model: https://alphacephei.com/vosk/models
  Set VOSK_MODEL_PATH or place model in vosk-models/ directory
```

### Использование с рецептами

```
You: voice
🎤 Recording... (speak now, 5 seconds)
✓ Recognized: recipe вегетарианский ужин на двоих
AI (Recipe Mode): [рецепт вегетарианского ужина]
```

## Ограничения

1. **Требуется модель Vosk**: Для полностью оффлайн распознавания речи требуется загрузить модель Vosk (см. выше).

2. **Платформенная поддержка**:
   - ✅ Linux (arecord, sox)
   - ✅ macOS (sox, rec)
   - ⚠️ Windows (ограниченная поддержка)

3. **Длительность записи**: По умолчанию записывается 5 секунд аудио. Это можно изменить в коде.

4. **Качество распознавания**: Зависит от:
   - Качества микрофона
   - Фонового шума
   - Ясности произношения
   - Используемой модели Vosk

## Устранение неполадок

### Ошибка "Speech recognition is not available"

**Проблема**: Не установлены инструменты для записи аудио.

**Решение**:
- Linux: `sudo apt-get install alsa-utils sox`
- macOS: `brew install sox`

### Ошибка "Failed to record audio"

**Проблема**: Микрофон не подключен или не настроен.

**Решение**:
1. Проверьте подключение микрофона
2. Проверьте настройки аудио в системе
3. На Linux: проверьте, что ALSA настроен правильно

### Ошибка "Offline recognition requires Vosk model"

**Проблема**: Модель Vosk не загружена или путь не указан.

**Решение**:
1. Скачайте модель с https://alphacephei.com/vosk/models
2. Распакуйте модель
3. Установите переменную окружения `VOSK_MODEL_PATH`

### Низкое качество распознавания

**Проблема**: Распознавание работает плохо.

**Решение**:
1. Используйте модель большего размера (лучше качество)
2. Говорите четче и громче
3. Уменьшите фоновый шум
4. Используйте качественный микрофон

## Технические детали

### Архитектура

```
OfflineChatMain.kt
    └──> SpeechRecognitionService.kt
            ├──> System commands (arecord/sox) - запись аудио
            └──> Vosk (optional) - распознавание речи
    └──> LlmClientOkHttp.kt - отправка в LLM
```

### Зависимости

- `com.alphacephei:vosk:0.3.45` - библиотека Vosk для распознавания речи
- Системные команды: `arecord`, `sox` (для записи аудио)

### Формат аудио

- **Sample rate**: 16000 Hz
- **Channels**: 1 (моно)
- **Bit depth**: 16 bit
- **Format**: WAV

Это стандартный формат для распознавания речи и совместим с Vosk.
