## Особенности реализации

1. **Умное определение типа запроса**: Ассистент автоматически определяет, нужен ли RAG (для вопросов о проекте) или MCP инструменты (для управления задачами)

2. **Зависимости задач**: Учитываются связи `blockedBy` и `blocks` для умных рекомендаций

3. **Приоритизация**: Рекомендации основаны на:
   - Приоритете задачи (critical > high > medium > low)
   - Зависимостях (задачи, блокирующие другие, приоритетны)
   - Статусе (заблокированные задачи требуют внимания)
   - Сроке выполнения (просроченные задачи срочны)

4. **Интеграция RAG + MCP**: Ассистент может комбинировать знания о проекте (RAG) с информацией о задачах (MCP)
