# Team Assistant - Troubleshooting

## Проблема: Текст переписывается при вводе в консоль

### Симптомы
При запуске через `./gradlew :console-agent:run --args="--team-assistant"` после определенного символа начинается переписывание запроса, текст начинает заменять уже написанный.

### Причина
Gradle может неправильно обрабатывать интерактивный ввод (stdin) при использовании `--args`. Это связано с буферизацией и перенаправлением потоков.

### Решение

**Рекомендуемый способ: Использовать JAR напрямую**

```bash
# 1. Собрать и установить
./gradlew :console-agent:installDist

# 2. Запустить через JAR
./console-agent/build/install/console-agent/bin/console-agent --team-assistant
```

Этот способ обеспечивает правильную работу интерактивного ввода.

### Альтернативные решения

1. **Использовать System.console()** (уже реализовано)
   - Код теперь использует `System.console()` для более надежного интерактивного ввода
   - Автоматически переключается на `readLine()` если консоль недоступна

2. **Проверить терминал**
   - Убедитесь, что вы используете настоящий терминал (не IDE встроенный)
   - Попробуйте запустить в отдельном терминале

3. **Использовать другой терминал**
   - macOS: Terminal.app, iTerm2
   - Linux: gnome-terminal, xterm
   - Windows: PowerShell, cmd.exe

### Технические детали

Проблема возникает из-за:
- Буферизации stdin/stdout в Gradle
- Конфликтов между главным процессом и дочерними процессами (Tasks MCP server)
- Неправильной настройки стандартных потоков

**Исправления в коде:**
- Добавлено использование `System.console()` для интерактивного ввода
- Добавлен `System.out.flush()` для немедленного отображения промпта
- Настроены стандартные потоки в `build.gradle.kts`

### Проверка работы

После исправлений, интерактивный ввод должен работать корректно:
- Промпт `> ` отображается сразу
- Ввод текста не переписывается
- Можно использовать стрелки для редактирования (если поддерживается терминалом)
- Enter отправляет команду
