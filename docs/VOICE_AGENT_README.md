# Голосовой агент (Voice Agent)

Голосовой агент позволяет взаимодействовать с локальной LLM моделью через голосовые команды.

## Функциональность

Голосовой агент реализует следующий поток:
1. **Speech → Text**: Распознавание речи с помощью Android SpeechRecognizer
2. **Text → LLM**: Отправка распознанного текста в локальную LLM модель
3. **LLM → Text**: Получение текстового ответа от модели

## Требования

1. **Разрешения**:
   - `RECORD_AUDIO` - для записи голоса
   - Разрешение запрашивается автоматически при первом использовании

2. **Локальная LLM**:
   - Должен быть запущен локальный LLM сервер (Ollama, LM Studio, vLLM)
   - Настроен в `Config.LOCAL_LLM_BASE_URL` (по умолчанию: `http://10.0.2.2:11434/v1/`)
   - Модель по умолчанию: `local:qwen2:7b`

3. **Поддержка распознавания речи**:
   - Устройство должно поддерживать Android SpeechRecognizer
   - Рекомендуется наличие Google Speech Services

## Использование

1. Откройте приложение
2. Перейдите в главный экран чата
3. Нажмите на кнопку "🎤 Voice" в панели действий
4. Нажмите на большую кнопку микрофона для начала записи
5. Говорите вашу команду или вопрос
6. Дождитесь распознавания текста
7. Ответ от LLM появится автоматически

## Примеры команд

- **Вычисления**: "Посчитай 25 умножить на 17"
- **Определения**: "Дай определение слова 'алгоритм'"
- **Развлечения**: "Расскажи анекдот"
- **Объяснения**: "Объясни, что такое машинное обучение"

## Технические детали

### Архитектура

- **SpeechRecognizerService**: Сервис для распознавания речи
  - Использует Android `SpeechRecognizer`
  - Поддерживает русский язык (`ru-RU`)
  - Возвращает Flow с распознанным текстом

- **VoiceAgentViewModel**: ViewModel для управления состоянием
  - Управляет процессом распознавания речи
  - Отправляет запросы в LLM через `ChatRepository`
  - Сохраняет историю разговора

- **VoiceAgentScreen**: UI экран
  - Отображает статус записи
  - Показывает распознанный текст
  - Отображает ответ от LLM

### Настройка модели

По умолчанию используется модель `local:qwen2:7b`. Чтобы изменить модель, отредактируйте `VoiceAgentViewModel`:

```kotlin
private val modelName = "local:qwen2:7b" // Измените на нужную модель
```

### Поддерживаемые языки

По умолчанию настроен русский язык. Чтобы изменить язык, отредактируйте `SpeechRecognizerService`:

```kotlin
putExtra(RecognizerIntent.EXTRA_LANGUAGE, "ru-RU") // Измените на нужный язык
```

## Устранение неполадок

### Ошибка "Speech recognition is not available"
- Убедитесь, что на устройстве установлены Google Speech Services
- Проверьте, что устройство поддерживает распознавание речи

### Ошибка "RECORD_AUDIO permission is required"
- Предоставьте разрешение при запросе
- Если разрешение не запрашивается, проверьте настройки приложения

### Ошибка "Failed to get response from LLM"
- Убедитесь, что локальный LLM сервер запущен
- Проверьте настройки `LOCAL_LLM_BASE_URL` в `Config.kt`
- Для эмулятора используйте `http://10.0.2.2:PORT/v1/`
- Для физического устройства используйте IP адрес компьютера

### Распознавание не работает
- Проверьте микрофон устройства
- Убедитесь, что нет других приложений, использующих микрофон
- Попробуйте говорить четче и громче
